# VR-тренажёр для реабилитации после инсульта

Учебный проект, в котором классификация сигналов ЭЭГ связана с 3D-сценой в Unity. Предсказание модели определяет, какая виртуальная рука будет двигаться к мишени.

Проект разработан в рамках курсовой работы **«Разработка VR-тренажёра с биологической обратной связью для реабилитации после инсульта»**.

## Как это работает

В проекте три основные части:

1. **Python-модель** анализирует запись ЭЭГ и предсказывает один из двух классов: `left_hand` или `right_hand`.
2. **FastAPI** получает предсказание и передаёт его в Unity через WebSocket.
3. **Unity** двигает соответствующую виртуальную руку к мишени, проверяет результат и показывает визуальную обратную связь.

При достижении мишени засчитывается повторение упражнения. После пяти успешных повторений упражнение завершается.

Для демонстрации используется воспроизведение записанной ЭЭГ, а не поток сигналов от человека в реальном времени.

## Технологии

- Python
- MNE, NumPy, pandas, scikit-learn
- CSP и LDA для классификации ЭЭГ
- FastAPI и WebSocket
- Unity 2021.3
- C#

## Результаты модели

Качество модели оценивалось методом Leave-One-Group-Out.

| Метрика | Результат |
|---|---:|
| Средняя точность | 50,59% |
| Стандартное отклонение | 5,01 процентного пункта |
| Классы | `left_hand`, `right_hand` |

Точность модели пока ограничена. Поэтому её предсказания используются как экспериментальные команды для виртуальной среды, а не как надёжное распознавание намерений человека.

## Запуск проекта

### 1. Подготовка Python

Нужен установленный Python. Из корневой папки проекта выполни:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r python\requirements.txt
```

### 2. Подготовка данных

Для обучения и воспроизведения модели необходим исходный датасет ЭЭГ. Он не входит в репозиторий.

В файлах `train_eeg.py` и `replay_eeg.py` нужно указать путь к датасету на своём компьютере.

Готовая модель находится в `python/motor_imagery_model.joblib`. Если её нет, сначала выполни обучение из папки `python`:

```bat
cd python
python train_eeg.py
```

### 3. Запуск FastAPI

Из папки `python` выполни:

```bat
uvicorn main:app --host 127.0.0.1 --port 8000
```

Для проверки API открой в браузере `http://127.0.0.1:8000/health`. При успешном запуске сервер вернёт статус `ok`.

### 4. Запуск Unity

Открой папку `unity` в Unity 2021.3, дождись импорта ресурсов и запусти сцену тренажёра.

### 5. Воспроизведение ЭЭГ

В отдельном терминале из папки `python` выполни:

```bat
python replay_eeg.py
```

Скрипт будет отправлять предсказания модели в FastAPI. Unity получит команды и запустит движение соответствующей виртуальной руки.

## Ограничения

- Используются заранее записанные сигналы ЭЭГ, а не данные с живого EEG-устройства.
- Точность классификации ограничена.
- Проект не является медицинским устройством.
- Успешное достижение мишени подтверждает работу механики упражнения, но не доказывает эффективность реабилитации.

## О проекте

Цель проекта — проверить, как можно объединить обработку ЭЭГ на Python, передачу данных через API и интерактивную 3D-сцену в Unity. Основной результат — работающий прототип, в котором предсказание модели связано с движением виртуальных рук и визуальной обратной связью.
